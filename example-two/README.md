# Worked Example Two: Not Actually a Quiet Case

The first [example](../example/) tests three genuine "gone quiet" situations. This one tests something different: a case that looks similar on the surface but is not actually a follow-up decision at all, because a reply already exists.

- [case.md](case.md): a volunteer who replied with genuine hesitation, not silence
- [output.md](output.md): the response, which correctly recognises this needs a direct reply, not a follow-up decision
- [review.md](review.md): whether the tool correctly stayed within its own actual scope
