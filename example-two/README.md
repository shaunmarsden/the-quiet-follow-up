# Worked Example Two: Not Actually a Quiet Case

The first [example](../example/) tests three real "gone quiet" situations. This one tests a case that looks similar but isn't a follow-up decision at all, because the person has already replied.

- [case.md](case.md): a volunteer who replied with real doubts, rather than going silent
- [output.md](output.md): the response, which sees that this needs a direct reply, not a follow-up decision
- [review.md](review.md): whether the tool stayed within what it's for

The repository doesn't record which model wrote this response, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
