# Human Review Checklist

Run through this before sending anything.

- [ ] A decision was actually made (follow up now, wait, answer something first, and so on) before any message was drafted
- [ ] The message is anchored to something real and specific, not "just checking in" or similar filler
- [ ] This is genuinely a gone-quiet situation, not a live reply that needs a direct response instead
- [ ] An explicit decline was respected, with nothing drafted to send
- [ ] Previous messages were not referenced as pressure, except deliberately in a genuine close-out
