# Human Review Checklist

Go through this before you send anything.

- [ ] The tool made a decision (follow up now, wait, answer something first and so on) before drafting any message
- [ ] The message is tied to something real and specific, not "just checking in" or similar filler
- [ ] The person really has gone quiet; this isn't a live reply that needs a direct answer instead
- [ ] If they clearly said no, that was respected, with nothing drafted to send
- [ ] The message doesn't use earlier messages as pressure, unless it's a deliberate close-out
