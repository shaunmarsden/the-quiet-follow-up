# Worked Example

Three made-up cases. A food bank's volunteer coordinator follows up with three people who signed up for a shift and went quiet. Each case tests a different decision.

- [cases.md](cases.md): the three cases as given
- [output.md](output.md): the decision [SKILL.md](../SKILL.md) made for each, including a weak message shown and rejected next to the one it drafted
- [review.md](review.md): whether it told the cases apart, especially the one with an unanswered question, which needed an answer first, and the clear no, which needed nothing sent

The repository doesn't record which model wrote these decisions, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
