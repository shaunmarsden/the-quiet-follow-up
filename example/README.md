# Worked Example

Three entirely fictional cases, a food bank volunteer coordinator following up with three people who signed up for a shift and went quiet, each testing a different decision.

- [cases.md](cases.md): the three cases as given
- [output.md](output.md): the decision [SKILL.md](../SKILL.md) makes for each, including a weak anchor shown and rejected next to the actual message drafted
- [review.md](review.md): whether each case was told apart from the others, particularly the unanswered-question case, which needed an answer before anything else, and the explicit decline, which needed nothing sent at all
